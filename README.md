Leonida Legend — a fully offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy carries its official name, description and grade, plus a guide written for this tracker that names its sources. It has a checklist saved in localStorage with export/import, filters by kind (story, missable, collectibles, activities, meta), grade and status, a spoiler shield that hides story trophies until earned, a seven-stage roadmap to the platinum, missable flags with reasons, and per-trophy counters for trophies whose official description carries a number (250 stunts, 100 WAiNK locations, and more).

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
